# Personal Portfolio Website

A responsive two-page portfolio website made with HTML, CSS, and JavaScript.

## Features

- Home page with an introduction, skills, and project cards
- Contact page with editable example links
- Responsive navigation for mobile devices
- Light/dark theme switcher stored in the browser
- Semantic HTML and a keyboard-accessible skip link

## Run locally

Open `index.html` in a browser, or use a local development server such as VS Code Live Server.

## Customize before publishing

Replace **Alex Morgan**, `hello@example.com`, and the sample GitHub/LinkedIn URLs with your own information. Update the project cards with real work before publishing through GitHub Pages.
