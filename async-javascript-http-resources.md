## Quick recall

- **Promise:** future result of an async operation; it becomes fulfilled or rejected.
- **async / await:** syntax over promises. `await` pauses only the current async function until the promise settles.
- **HTTP:** client requests a resource from a server. `200` means success; `404` means the resource was not found.
- **HTTPS:** encrypted HTTP; use it whenever personal or sensitive data is involved.
